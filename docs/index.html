Prati igrača

Rejting i turnire novog igrača skripta popuni za minutu-dvije.

Postavke

  1. Otvori GitHub → novi ključ (fine-grained).
  2. Repository access: Only select repositories → odaberi sah.
  3. Permissions: Contents = Read and write, Actions = Read and write.
  4. Generiraj ključ, kopiraj ga i zalijepi ovdje.

Ključ ostaje samo u ovom pregledniku na ovom uređaju. Treba ti za gumb Osvježi i za dodavanje igrača.
